# 💸 Expense Tracker

A simple and clean **Expense Tracker Web App** that helps you track your daily spending easily.  
You can **add expenses**, **delete them anytime**, and it automatically shows your **total spending**.  
Your data stays saved even after refreshing the page using **Local Storage**.

---

## 🚀 Features

✅ Add daily expenses with:
- **Title**
- **Amount**
- **Date**

✅ Delete any expense from the list  
✅ Total spending updates dynamically  
✅ Data stays saved after refresh (LocalStorage)  
✅ Simple UI and easy to use for daily tracking

## 📂 How It Works

- User enters an expense (title, amount, date)
- It gets added to the list instantly
- Total amount gets updated
- Data is saved in LocalStorage automatically
- On refresh, the saved data loads again
